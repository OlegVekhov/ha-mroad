# Главная дорога — Home Assistant

Неофициальная интеграция баланса лицевых счетов «Главная дорога» через API, используемый официальным веб-кабинетом. Настройка по логину и паролю через интерфейс Home Assistant.

**Версия 0.1.0 — экспериментальная.** Запросы восстановлены по публичному JavaScript личного кабинета 11.10.2026. Локальные тесты используют подставные ответы; вход на реальном аккаунте и запуск в Home Assistant ещё не проверены. API не документирован оператором и может измениться.

## Возможности

- Баланс в рублях и статус каждого лицевого счёта.
- Обновление каждые 15 минут; в настройках можно выбрать от 5 до 1440 минут.
- Повторная авторизация при HTTP/API ошибке 401 или 403.
- Запрос повторного ввода пароля, если повторный вход отклонён.
- Новые счета добавляются автоматически; исчезнувшие становятся недоступными.

Статус датчика — статус **счёта из API**, а не гарантия работоспособности отдельного транспондера. История поездок, автопополнение и управление транспондерами в эту версию не входят.

## Установка через HACS

Требуется Home Assistant 2025.1 или новее и HACS.

1. HACS → меню ⋮ → Пользовательские репозитории.
2. Добавьте адрес опубликованного репозитория, категория **Интеграция**.
3. Найдите «Главная дорога», скачайте и перезапустите Home Assistant.
4. Настройки → Устройства и службы → Добавить интеграцию → «Главная дорога».
5. Введите логин и пароль личного кабинета.

Необходимо проверить, что баланс каждого счёта совпадает с личным кабинетом. При неправильном пароле настройка должна завершиться ошибкой. Для проверки обновления используйте действие `homeassistant.update_entity` для датчика баланса.

## Ручная установка

Скопируйте папку `custom_components/mroad` в `/config/custom_components/mroad` и перезапустите HA. Затем добавьте интеграцию через интерфейс.

## Уведомление о низком балансе

В интерфейсе HA создайте автоматизацию с триггером «Числовое состояние»: выберите нужный датчик баланса, задайте свой порог и добавьте уведомление. У каждого счёта свой датчик; имя сущности смотрите в HA.

## Данные доступа

Пароль хранится штатно в конфигурационной записи Home Assistant. Токен хранится только в памяти. Интеграция не выводит пароль, токен или URL авторизованных запросов в свои журналы. API официального клиента передаёт параметры по HTTPS в строке запроса, поэтому не включайте подробное журналирование HTTP-запросов.

## Создание репозитория

Из корня проекта на компьютере с Git и GitHub CLI:

```bash
gh auth login
git init -b main
git add .
git commit -m "Add experimental MRoad integration 0.1.0"
gh repo create ha-mroad --public --source=. --remote=origin --push
git tag v0.1.0
git push origin v0.1.0
```

В `manifest.json` адреса документации и ошибок изначально указывают на `olegvekhov/ha-mroad`. Если публикуете в другой аккаунт или под другим именем, измените эти два адреса до первого коммита. Команды выше создают публичный репозиторий в аккаунте, авторизованном в `gh`.

## Выпуск обновления

```bash
python scripts/version.py 0.1.1
git add .
git commit -m "Release 0.1.1"
git push origin main
git tag v0.1.1
git push origin v0.1.1
```

GitHub Actions проверяет совпадение тега с версией, запускает тесты и создаёт релиз с архивом `mroad.zip`. HACS может получать обновления из этого репозитория. Перед релизом убедитесь, что проверка hassfest для коммита прошла.

## Проверки разработки

```bash
python -m pip install aiohttp
python -m compileall -q custom_components scripts
python -m unittest discover -s tests -v
```

Исходники публичного клиента: `https://lk.m-road.ru/`. База API: `https://onyma-api.m-road.ru/onyma/system/api/json`. Приложение вызывает `open_session` с параметрами `user`, `pass`, `realm=nqr.client`, затем `onm_api_nqr_api_contract_info` с токеном. Баланс читается из `remainder`.
